# Weave v0.4 — 05 组合与示例（调用方）

> 状态：修订注 R-2026 —— 原 DX 层（weave.yaml 装配 / builder / call_sync / CLI init）**已移出 weave**；
> weave 不提供配置装配、CLI 与"零配置 Agent"。本节说明调用方如何只用原子件组合，示例在 `demos/atomic/`。

## 1. 为什么没有 Agent/CLI/装配器

weave 只给原子件；"用什么循环、上下文放什么、历史存哪、谁来装配"都是业务决策。
需要脚手架时，从 `demos/atomic/` 复制示例代码到自己项目里改，而不是引一个框架 API。

## 2. 最小编排（只用 weave.core + providers + stores）

```python
import asyncio
from weave.core.types import Message
from weave.providers.openai_compat import OpenAICompatibleProvider
from weave.stores.memory import InMemoryStateStore

provider = OpenAICompatibleProvider()          # 凭证：OPENAI_API_KEY / DEEPSEEK_API_KEY
store = InMemoryStateStore()

async def chat_once(prompt: str) -> str:
    # 你的"循环"：这里只是单回合；要不要历史/工具全由你决定
    resp = await provider.complete([Message(role="user", content=prompt)])
    return resp.content

print(asyncio.run(chat_once("你好")))
```

## 3. 常用组合点（都是调用方代码）

| 需求 | 怎么做 |
|------|--------|
| 多轮历史 | 自己定义 (namespace, key)，`await store.append(ns, key, {...})` 写、`get` 读；示例 `demos/atomic/context_builder.py` |
| 工具循环 | 自己写 while + `ToolRegistry`；示例 `demos/atomic/loop.py::run_turn` |
| 工具绑定 | 实现 `ToolRegistry` 两个方法；示例 `demos/atomic/tool_registry.py` |
| 可观测/事件 | 实现 `EventSink` 并在你的循环关键点 `emit`；`weave.capabilities.trace.TraceSink` 可直接用 |
| 快照/回滚 | `weave.capabilities.checkpoint.CheckpointManager`（需 store 支持 `ListableStore`） |
| 整装容器 | 业务自己的 `DemoAgent` 式类（示例 `demos/atomic/agent.py`） |

## 4. 凭证与模型

凭证/模型解析是 `OpenAICompatibleProvider` 构造器内部的便利（env `OPENAI_API_KEY`/
`DEEPSEEK_API_KEY`、`WEAVE_MODEL` 等），与循环/上下文无关；显式传入 api_key/model/base_url 亦可。

## 5. 不再存在的能力（v0.3 对照）

- `python -m weave init` / `weave` CLI → 已移除；
- `build_agent_from_yaml` / weave.yaml 装配 / `call_sync` → 已移除（配置装配是业务代码）；
- "零配置 `Agent()`" → 已移除（无 Agent）。
